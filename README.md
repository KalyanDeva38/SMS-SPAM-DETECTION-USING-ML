# SMS-SPAM-DETECTION-USING-ML
# SMS Spam Detection using Machine Learning

## About
A text classification model that detects spam messages with high accuracy.
Built as part of academic research and published in the International Journal 
of Science, Engineering and Technology (IJESET).

## Technologies Used
- Python
- Naive Bayes Algorithm
- Support Vector Machine (SVM)
- Natural Language Processing (NLP)

## Features
- Classifies SMS messages as Spam or Ham (Not Spam)
- NLP-based preprocessing (tokenization and vectorization)
- High accuracy on real-world datasets
